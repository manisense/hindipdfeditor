Data Safety Summary

This page summarizes the app's expected Google Play Data Safety declaration in plain English.

Overview

  • Core PDF editing works without developer-hosted document storage.
  • No account is required.
  • No ads SDK is included.
  • No analytics SDK is included in the Android app.
  • The website uses Google Analytics 4 (G-1K5ZEEBHE5) for aggregate page traffic only — not for PDFs you open in the tools.
  • Optional AI OCR sends the current page image through our secured API to Google Gemini only by user action.
  • Web and Android Translate send detected text lines through the same secured API; both Hindi → English and English → Hindi are supported. On the web, an affected page image may also be processed for OCR when local text extraction is flagged as unreliable and the translation consent screen explicitly discloses the fallback.

Data Types

Data Collected or shared? Purpose Required?
PDF page image Processed by our API and Google only for user-consented AI OCR or the disclosed web Translate OCR fallback. Text detection for difficult scans or unreliable PDF text maps. No.
Detected text lines Processed by our API and Google only if Translate is used. Hindi ↔ English translation. No.
Opened PDFs and edits Processed locally by the app. Open, preview, edit, and export PDFs. Yes for app functionality.
Anonymous usage metadata Stored as a client hash plus daily document/page counts. Abuse prevention and free quota enforcement. No — only when an AI feature is used.

Security Practices

  • Network requests for optional AI use HTTPS.
  • The Gemini API credential is stored only as a server secret.
  • Document content is not written to quota storage or content logs.
  • The original PDF is not overwritten; exports create a new file.

Data Not Collected By Developer

The developer does not collect name, email, phone number, contacts, location, financial information, advertising identifiers, or analytics events through developer-operated servers or SDKs.

Deletion

There is no developer-hosted account data to delete. Users can delete local app data by clearing app storage or uninstalling the app. Exported PDFs remain wherever the user saved or shared them.
