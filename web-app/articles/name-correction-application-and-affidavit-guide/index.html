Name correction application and affidavit: admission certificate errors

Contact the issuer about an admission certificate name error. Prepare your correction request PDF and obtain any required affidavit format from the authority.

Written by Manish · Reviewed 2026-10-01

Direct answer

Ask the issuer for its correction process. You can prepare a request and supporting evidence as PDFs, but editing the issued certificate yourself is not an official correction. Make an affidavit only if required.

Start with the issuer

If an admission certificate has an error, consult the examination authority’s current instructions and contact details. Editing the candidate name, roll number, photograph or centre yourself does not make it an official correction.

An application is not an affidavit

A correction application explains the mismatch. Prepare an affidavit only when the authority requires one and specifies the format. Do not assume one affidavit, stamp value or attestation rule applies to every examination.

Prepare your request

Keep the original admission certificate and copies of supporting identity or education evidence. Explain the recorded information, the correct information and the supporting proof. Use a PDF editor to fill your own request, not to alter an issued certificate as an authorized correction.

Fictional request example

“Subject: request to reconcile name spelling. Please review my information against the attached evidence. Applicant: Test Kumar.” This is a practice sentence, not a legal affidavit or an institution-approved format.

Frequently asked questions

Can I change the name on my admission certificate myself?

Do not treat a self-edited PDF as an authorized replacement. Obtain the corrected certificate from the issuer.

Is an affidavit always required?

No universal requirement is assumed. Ask the relevant authority for the current requirements and format.
