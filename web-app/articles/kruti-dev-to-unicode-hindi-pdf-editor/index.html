Kruti Dev PDF Showing Gibberish? How to Read, Convert or Edit It

Kruti Dev is still the font of choice in many government offices, courts and typing tests, so these PDFs keep turning up. They look fine on paper, but copy a line and you get "d`fr nso". Here's what's going on and three ways to work with them, depending on what you actually need.

By Manish · Updated 25 September 2026 · about 5 minutes to read

Short answer

Kruti Dev stores Hindi shapes on ordinary English keyboard letters, so without the font you see the English letters underneath. To get real Hindi text, copy it out and run it through a Kruti Dev–to–Unicode converter, then proofread. To change just a few words on the PDF itself, use the Hindi PDF Editor Android app's replacement mode. The web editor detects Kruti Dev and switches editing off for that page.

Why Kruti Dev turns into "d`fr nso"

Modern Hindi text uses Unicode: every letter, from क to the matra ि, has its own code, so any phone or computer knows it's Hindi. Kruti Dev predates that. It follows the Remington typewriter layout: pressing the "d" key gives you the shape of क, but the file still stores the letter "d". The font just draws it as Hindi.

That trick works as long as everyone has Kruti Dev installed. The moment the text leaves that font, by copying, searching, translating, or opening on a phone without it, the English letters show through. "कृति देव" comes out as "d`fr nso", and "हिन्दी" as "fgUnh".

It also explains why ordinary PDF editors struggle. They see English letters, so editing a word inserts English letters in a different font, and your sentence turns into a mix of Hindi and gibberish.

First, decide what you actually need

  • You need the text to reuse, search or send it: convert it (option 1).
  • You need the whole document in Unicode to keep editing it: convert, then rebuild the document (option 2).
  • You need the PDF itself with a few words changed: overlay new text (option 3).

Option 1: Convert the text to Unicode

  1. Open the PDF and copy the Hindi text. It will paste as English gibberish, and that's expected.
  2. Paste it into a free Kruti Dev–to–Unicode converter. Rajbhasha.net and several typing sites offer one, and they all work the same way: they map each English letter back to its Hindi character.
  3. Proofread the result carefully. Converters get most text right but often trip on the short-i matra, the reph (र्), nukta letters and punctuation, because PDFs sometimes store Kruti Dev characters in a slightly different order than a Word file does.

If copying gives you nothing at all, the PDF is a scan. Run it through OCR (Google Lens or Google Drive's "Open with Google Docs") instead. OCR reads the printed Hindi directly and skips Kruti Dev entirely.

Option 2: Rebuild the document in Unicode

If this document will be edited again and again, a one-time rebuild pays off. Paste the converted text into Word or Google Docs, set it in a Unicode font such as Mangal or Noto Sans Devanagari, and recreate the layout. From then on, anyone can open, search and edit it without Kruti Dev installed. Export PDFs with fonts embedded.

Option 3: Change a few words on the PDF itself

Sometimes rebuilding makes no sense. You just need one date or one name changed on a notice, and the rest has to stay exactly as it is.

On the web: Hindi PDF Editor checks the fonts when you open a PDF. If a page uses Kruti Dev or another legacy font, it tells you which one and switches editing off for that page. The text there can't be edited safely, and guessing would put garbled letters into your document.

In the Android app: there is a safe replacement mode for pages with a positively identified legacy font.

1. Open the PDF in the app

Open the file in the Hindi PDF Editor Android app. It warns you that the page uses a legacy font.

2. Turn on replacement for that page

After you confirm, the original page is kept as an image, exactly as it looks, and can no longer be changed underneath.

3. Cover the old words and type the new ones

Cover the words you want to replace and type the new text in Unicode Hindi. It is set in a Unicode font, not Kruti Dev, so it will look slightly different from the surrounding text.

4. Export a new PDF

You get a new file that looks the same on every device. The original is left untouched, and the old Kruti Dev text is still not converted.

If the app can't identify the font at all, it treats the page as unsafe and keeps editing off. It never assumes the text is fine.

Stop creating new Kruti Dev files

If your office still types in Kruti Dev, you don't have to relearn the keyboard. Windows includes a Hindi keyboard, and Google Input Tools and Gboard do too. Unicode typing tools also offer a Remington-style layout (sometimes called Remington GAIL or CBI), so typists keep their muscle memory and every new file is Unicode.

Other questions people ask

How do I know if a PDF uses Kruti Dev?

Copy a Hindi line and paste it into Notepad or WhatsApp. If you get English letters and symbols like 'd`fr nso' or 'fgUnh', it's a legacy font such as Kruti Dev, DevLys or Chanakya. Real Unicode Hindi pastes as Hindi.

Does Hindi PDF Editor convert Kruti Dev to Unicode?

No. It detects Kruti Dev and similar fonts. On the web, editing is switched off for those pages. The Android app can replace text on them in a Unicode font after you confirm. In both cases the existing Kruti Dev text is not converted.

Why do government offices still use Kruti Dev?

Kruti Dev follows the old Remington typewriter keyboard, so typists trained on typewriters could move to computers without relearning. Many state typing tests still use it, which keeps it in daily use.

Is your PDF in Kruti Dev?

Open it in the editor to check. It tells you which pages use a legacy font. For Unicode PDFs you can edit the Hindi text right away, free and without uploading.
